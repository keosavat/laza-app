# LAZA app — ລະບົບ POS ຮ້ານອາຫານ (Phase 1: Core POS)

## ຕິດຕັ້ງ ແລະ ເປີດໃຊ້
ຕ້ອງມີ **Node.js 22.13 ຂຶ້ນໄປ** (ທົດສອບກັບ Node 24). ບໍ່ຕ້ອງຕິດຕັ້ງຖານຂໍ້ມູນແຍກ (ໃຊ້ SQLite ທີ່ມີໃນ Node).

```powershell
npm install
npm run build      # ສ້າງໜ້າເວັບ
npm start          # ເປີດທີ່ http://localhost:4000
```
ເຄື່ອງອື່ນໃນວົງ LAN (ແທັບເລັດພະນັກງານ, ຈໍຄົວ) ເຂົ້າໄດ້ທີ່ `http://<IP ເຄື່ອງນີ້>:4000`.

ໂໝດພັດທະນາ (hot reload): `npm run dev` → ໜ້າເວັບ http://localhost:5173
ທົດສອບອັດຕະໂນມັດ: `npm test`

ຂໍ້ມູນເກັບຢູ່ `server/data/laza.db` (ສຳຮອງໂດຍ copy ໄຟລ໌ນີ້ ຕອນປິດເຊີບເວີ).

## ບັນຊີທົດລອງ (ສ້າງອັດຕະໂນມັດຄັ້ງທຳອິດ)
ລະຫັດຜ່ານທຸກບັນຊີ: `laza1234` — **ກະລຸນາປ່ຽນກ່ອນໃຊ້ງານແທ້** (ເມນູ ພະນັກງານ)

| ຊື່ຜູ້ໃຊ້ | ໜ້າທີ່ | ສິດ |
|---|---|---|
| admin | ເຈົ້າຂອງຮ້ານ | ທຸກຢ່າງ |
| manager | ຜູ້ຈັດການ | ທຸກຢ່າງ ຍົກເວັ້ນຕັ້ງສິດເຈົ້າຂອງ |
| cashier | ແຄັດເຊຍ | ຂາຍ, ຮັບເງິນ, ສ່ວນຫຼຸດ, ກະ, ລາຍງານ |
| waiter | ພະນັກງານເສີບ | ເປີດໂຕະ, ສັ່ງອາຫານ, ພິມບິນ |
| kitchen | ຄົວ | ຈໍຄົວ |

## ຟັງຊັນໃນ Phase 1
- **ໂຕະ**: ແຜນໂຕະຕາມໂຊນ, ສະຖານະ (ວ່າງ / ມີລູກຄ້າ / ພິມບິນແລ້ວ), ເວລາທີ່ນັ່ງ, ຍ້າຍໂຕະ
- **ສັ່ງອາຫານ**: ເມນູຕາມໝວດ + ຄົ້ນຫາ, ຕົວເລືອກ (ຂະໜາດ/ຫວານ/ທັອບປິ້ງ ມີລາຄາເພີ່ມ), ໝາຍເຫດ, ກະຕ່າກ່ອນສົ່ງຄົວ
- **ຂາຍໜ້າຮ້ານ/ກັບບ້ານ**: ເລກຄິວອັດຕະໂນມັດຕໍ່ກະ, ພັກອໍເດີໄວ້
- **ຈໍຄົວ (KDS)**: ລໍຖ້າ → ກຳລັງເຮັດ → ພ້ອມເສີບ → ເສີບແລ້ວ, ສຽງແຈ້ງເຕືອນ, ເຕືອນສີແດງເມື່ອເກີນ 20 ນາທີ, ອັບເດດທັນທີ (realtime)
- **ຊຳລະເງິນ**: ເງິນສົດ / ໂອນ / QR / ບັດ, ກີບ-ໂດລາ-ບາດ, ແຍກຈ່າຍຫຼາຍວິທີ, ຄິດເງິນທອນ, ສ່ວນຫຼຸດ % ຫຼື ຈຳນວນ, ຄ່າບໍລິການ, VAT
- **ລາຍລະອຽດລາຍການ + ເລືອກຫຼາຍລາຍການ**: ກົດແຖວລາຍການເພື່ອເບິ່ງລາຍລະອຽດ (ແຍກລາຄາເມນູ/ຕົວເລືອກ, ໝາຍເຫດ, ຜູ້ສັ່ງ+ເວລາ); ຕິກເລືອກຫຼາຍລາຍການ ແລ້ວປ່ຽນສະຖານະ (ເສີບແລ້ວ/ກຳລັງເຮັດ/ພ້ອມເສີບ), ພິມໃບຄົວຄືນ ຫຼື ຍົກເລີກພ້ອມກັນ
- **ຍົກເລີກ**: ຍົກເລີກລາຍການ (ບາງສ່ວນໄດ້) ພ້ອມເຫດຜົນ — ສະເພາະຜູ້ຈັດການ, ບັນທຶກໃນ audit log
- **ກະ ແລະ ລິ້ນຊັກເງິນ**: ເປີດກະດ້ວຍເງິນທອນຕັ້ງຕົ້ນ, ສະຫຼຸບເງິນທີ່ຄວນມີ, ນັບເງິນຕອນປິດ ແລະ ສະແດງເງິນຂາດ/ເກີນ
- **ລາຍງານປະຈຳວັນ**: ຍອດຂາຍ, ກຳໄລຂັ້ນຕົ້ນ, ແຍກຕາມວິທີຊຳລະ / ຊົ່ວໂມງ / ໝວດ / ເມນູຂາຍດີ / ຜູ້ຮັບເງິນ, ແນວໂນ້ມ 7 ວັນ, ອໍເດີຄ້າງ
- **ພິມ**: ໃບສັ່ງຄົວ, ໃບແຈ້ງຍອດ, ໃບຮັບເງິນ (80mm) — ຕັ້ງຄ່າພິມອັດຕະໂນມັດແຍກແຕ່ລະເຄື່ອງ
- **ຈັດການ**: ເມນູ + ຮູບ + ຕົ້ນທຶນ, ໂຕະ/ໂຊນ (ເພີ່ມຫຼາຍໂຕະພ້ອມກັນ), ພະນັກງານ + ສິດ, ຕັ້ງຄ່າຮ້ານ/ພາສີ/ອັດຕາແລກປ່ຽນ

## QR ສັ່ງອາຫານ (ລູກຄ້າສະແກນເອງ)
1. ໜ້າ **ໂຕະ** → ກົດໂຕະວ່າງ → ໃສ່ຈຳນວນແຂກ → ເລືອກ "ໃຫ້ລູກຄ້າສະແກນ QR" (ກຳນົດໄລຍະເວລາໄດ້: ບໍ່ຈຳກັດ ຫຼື 1–4 ຊົ່ວໂມງ ສຳລັບບຸບເຟ່ຕ໌) → ໄດ້ QR ໃຫ້ພິມ (80mm) ຫຼື ສະແດງໃຫ້ລູກຄ້າສະແກນ. ເປີດຄືນໄດ້ຈາກປຸ່ມ **QR** ໃນໜ້າອໍເດີ.
2. ລູກຄ້າສະແກນ → ເບິ່ງເມນູ ເລືອກຕົວເລືອກ ໃສ່ກະຕ່າ ສັ່ງ → ເຫັນສະຖານະອໍເດີ ແລະ ຍອດແບບ realtime, ກົດ **ເອີ້ນພະນັກງານ / ຂໍບິນ** ໄດ້. ບໍ່ຕ້ອງ login ແລະ ບໍ່ຕ້ອງຕິດຕັ້ງແອັບ.
3. ພະນັກງານເຫັນລາຍການທັນທີ (ປ້າຍ "ລູກຄ້າສັ່ງເອງ") ພ້ອມສຽງ + ແຈ້ງເຕືອນມຸມຊ້າຍລຸ່ມ. ຕັ້ງຄ່າໄດ້ວ່າ **ສົ່ງເຂົ້າຄົວທັນທີ** ຫຼື **ລໍຖ້າພະນັກງານຢືນຢັນກ່ອນ** (ລາຍການທີ່ລໍຖ້າຍັງບໍ່ລວມໃນຍອດ ແລະ ຊຳລະເງິນບໍ່ໄດ້ຈົນກວ່າຈະຢືນຢັນ/ປະຕິເສດ).
4. ຊຳລະເງິນ ຫຼື ຍົກເລີກອໍເດີ → QR ໝົດອາຍຸທັນທີ. "ສ້າງໃໝ່" ຈະຍົກເລີກ QR ເກົ່າ.

**ສຳຄັນ — ໃຫ້ມືຖືລູກຄ້າເປີດໄດ້:** ໄປ **ຕັ້ງຄ່າ → QR ສັ່ງອາຫານ** ແລ້ວກົດເລືອກທີ່ຢູ່ຂອງເຄື່ອງແມ່ຂ່າຍ (ເຊັ່ນ `http://192.168.1.10:4000`). ລູກຄ້າຕ້ອງເຊື່ອມ Wi-Fi ດຽວກັບເຄື່ອງແມ່ຂ່າຍ. ຖ້າຢາກໃຫ້ສັ່ງໄດ້ຈາກນອກຮ້ານ ຕ້ອງຕິດຕັ້ງເທິງເຊີບເວີ ແລະ ໃຊ້ໂດເມນ https.
ຄວາມປອດໄພ: token ສຸ່ມ 192 ບິດ, ລາຄາຄິດຢູ່ເຊີບເວີ, ບໍ່ສົ່ງຕົ້ນທຶນໃຫ້ລູກຄ້າ, ຈຳກັດຄວາມຖີ່ການສັ່ງ (10 ຄັ້ງ/ນາທີ) ແລະ ການເອີ້ນ.

## ສະຕັອກ, ວັດຖຸດິບ ແລະ ສູດອາຫານ
1. ເມນູ **ສະຕັອກ** → ເພີ່ມວັດຖຸດິບ (ຊື່, ຫົວໜ່ວຍ, ຕົ້ນທຶນ/ຫົວໜ່ວຍ, ເຕືອນເມື່ອເຫຼືອ, ສະຕັອກເລີ່ມຕົ້ນ). ເຄື່ອງດື່ມຂາຍເປັນຂວດ ກໍເພີ່ມເປັນວັດຖຸດິບ 1 ຂວດ.
2. **ເມນູອາຫານ → ແກ້ໄຂເມນູ → ສູດອາຫານ**: ໃສ່ວັດຖຸດິບທີ່ໃຊ້ຕໍ່ 1 ຈານ (ເຊັ່ນ ເຝີ = ຊີ້ນງົວ 150g + ເສັ້ນ 100g). ເປີດ "ໃຊ້ຕົ້ນທຶນຈາກສູດ" ເພື່ອໃຫ້ຕົ້ນທຶນ ແລະ ກຳໄລຄິດເອງ ແລະ ປ່ຽນຕາມລາຄາວັດຖຸດິບ.
3. **ຊຳລະເງິນແລ້ວ** ລະບົບຕັດສະຕັອກຕາມສູດອັດຕະໂນມັດ (ລາຍການທີ່ຍົກເລີກບໍ່ຕັດ), ບັນທຶກໃນ "ປະຫວັດສະຕັອກ".
4. ຮັບສິນຄ້າເຂົ້າ (ຕົ້ນທຶນເປັນຄ່າສະເລ່ຍຖ່ວງນ້ຳໜັກ), ນັບສະຕັອກ (ຕັ້ງຍອດຈິງ), ຕັດເສຍຫາຍ.
5. ເມນູທີ່ສະຕັອກເຫຼືອ ≤ 5 ຈານ ຈະມີປ້າຍ "ເຫຼືອ n"/"ສະຕັອກໝົດ" ໃນໜ້າຂາຍ. **ລູກຄ້າສັ່ງຜ່ານ QR ບໍ່ໄດ້ເມື່ອເມນູໝົດ** (ພະນັກງານຍັງຂາຍໄດ້ ເຜື່ອສະຕັອກຍັງບໍ່ອັບເດດ). Dashboard ສະແດງວັດຖຸດິບທີ່ໃກ້ໝົດ.

## ລູກໜີ້ (ຕິດໜີ້)

- ຕອນຊຳລະເງິນ ຕິ໊ກ "ຕິດໜີ້" ແລ້ວເລືອກ/ສ້າງລູກຄ້າ — ສ່ວນທີ່ຍັງບໍ່ຈ່າຍຈະເຂົ້າບັນຊີລູກຄ້າ (ຈ່າຍບາງສ່ວນຕອນນີ້ + ຕິດໜີ້ສ່ວນທີ່ເຫຼືອໄດ້).
- ໜ້າ "ລູກໜີ້": ເບິ່ງໜີ້ຄ້າງ, ປະຫວັດ ແລະ ຮັບຊຳລະ (ເງິນສົດເຂົ້າລິ້ນຊັກຂອງກະທີ່ເປີດຢູ່; ໂອນ/QR/ບັດບໍ່ເຂົ້າລິ້ນຊັກ).
- ຜູ້ຈັດການຕັ້ງວົງເງິນຕິດໜີ້ສູງສຸດຕໍ່ລູກຄ້າໄດ້ (0 = ບໍ່ຈຳກັດ). ຮັບຊຳລະເກີນໜີ້ຄ້າງບໍ່ໄດ້.
- ລາຍງານປະຈຳວັນ ແລະ ສະຫຼຸບກະ ສະແດງຍອດຕິດໜີ້, ຍອດເກັບໜີ້ເກົ່າ ແລະ ໜີ້ຄ້າງລວມ.

## ລູກຄ້າ (CRM) ແລະ ຄະແນນສະສົມ

- ເມນູ **ລູກຄ້າ (CRM)**: ລາຍຊື່ລູກຄ້າ + ຈຳນວນຄັ້ງທີ່ມາ, ຍອດໃຊ້ຈ່າຍ, ມາລ່າສຸດ, ຄະແນນ; ກຸ່ມອັດຕະໂນມັດ (ໃໝ່ / ຊື້ຊ້ຳ / ປະຈຳ 5+ ຄັ້ງ / ຫາຍໄປ 60+ ວັນ), ວັນເກີດເດືອນນີ້, ປ້າຍກຳກັບ, ສົ່ງອອກ CSV. ກົດແຖວເບິ່ງໂປຣໄຟລ໌: ບິນ, ເມນູທີ່ສັ່ງບ່ອຍ, ປະຫວັດຄະແນນ.
- ຕອນຊຳລະເງິນ ຕິກ **ລູກຄ້າສະມາຊິກ** ເພື່ອຜູກບິນກັບລູກຄ້າ (ລູກຄ້າຕິດໜີ້ຖືກຜູກອັດຕະໂນມັດ).
- **ຕັ້ງຄ່າ → ຄະແນນສະສົມ**: ໃຊ້ຈ່າຍທຸກໆ ? ກີບ ໄດ້ 1 ຄະແນນ, ແລະ 1 ຄະແນນ ແລກສ່ວນຫຼຸດ ? ກີບ (0 = ປິດ). ຄ່າເລີ່ມຕົ້ນປິດຢູ່.
- ແລກຄະແນນຕອນຊຳລະ: ຫຼຸດຍອດທີ່ຕ້ອງຈ່າຍ (ຍອດບິນບໍ່ປ່ຽນ, ບໍ່ເຂົ້າລິ້ນຊັກ). ຄະແນນຄິດຈາກຍອດຫຼັງຫັກຄະແນນ ແລະ ປັດລົງ. ຜູ້ຈັດການປັບຄະແນນດ້ວຍມືໄດ້ (ບໍ່ຕິດລົບ).

## ຈັດຊື້ / ຜູ້ສະໜອງ

- ເມນູ **ຈັດຊື້ / ຜູ້ສະໜອງ** (ຜູ້ຈັດການ): ແຖບ **ຜູ້ສະໜອງ** (ຊື່, ຜູ້ຕິດຕໍ່, ເບີໂທ, ທີ່ຢູ່, ຍອດຄ້າງຈ່າຍ) ແລະ ແຖບ **ໃບສັ່ງຊື້**.
- ຕັ້ງ **ຜູ້ສະໜອງປະຈຳ** ໃນແຕ່ລະວັດຖຸດິບ (ໜ້າສະຕັອກ). ປຸ່ມ **ແນະນຳຈາກສະຕັອກ** ຈະລວມວັດຖຸດິບທີ່ໃກ້ໝົດ (ຕ້ອງຕັ້ງ "ເຕີມໃຫ້ເຖິງ") ແບ່ງຕາມຜູ້ສະໜອງ, ປັດຈຳນວນຂຶ້ນຕາມແພັກ, ແລະ ບໍ່ແນະນຳຊ້ຳສິ່ງທີ່ສັ່ງແລ້ວ.
- ຂັ້ນຕອນໃບສັ່ງຊື້: ສະບັບຮ່າງ (ແກ້ໄຂໄດ້) → ສັ່ງແລ້ວ → ໄດ້ບາງສ່ວນ → ຮັບຄົບ. ຍົກເລີກໄດ້ກ່ອນຮັບເຄື່ອງ; ຖ້າຜູ້ສະໜອງສົ່ງບໍ່ຄົບ ກົດ "ປິດ (ບໍ່ຮັບເພີ່ມ)".
- **ຮັບເຄື່ອງ** (ທັງໝົດ ຫຼື ບາງສ່ວນ): ສະຕັອກເພີ່ມທັນທີ, ຕົ້ນທຶນເຉລ່ຍຖືກປັບຕາມລາຄາຈິງ, ບັນທຶກລັອດ/ວັນໝົດອາຍຸ ແລະ ເລກໃບສົ່ງເຄື່ອງ. ຮັບເກີນຈຳນວນສັ່ງບໍ່ໄດ້.
- **ຍອດຄ້າງຈ່າຍ** = ມູນຄ່າເຄື່ອງທີ່ຮັບແລ້ວ − ເງິນທີ່ຈ່າຍ. ບັນທຶກການຈ່າຍເປັນງວດໄດ້ (ເງິນສົດ/ໂອນ) ແຕ່ເປັນການຕິດຕາມໜີ້ເທົ່ານັ້ນ ບໍ່ຫັກອອກຈາກລິ້ນຊັກເງິນ.

## ຈອງໂຕະ

- ເມນູ **ຈອງໂຕະ**: ເບິ່ງການຈອງເປັນມື້ (ມື້ກ່ອນ/ມື້ໜ້າ), ຈອງໃໝ່ (ຊື່, ເບີໂທ, ວັນ-ເວລາ, ຈຳນວນຄົນ, ໄລຍະນັ່ງ, ໂຕະ, ໝາຍເຫດ), ແກ້ໄຂ, ຍົກເລີກ, ໝາຍ "ບໍ່ມາ" ແລະ ກູ້ຄືນ.
- ເລືອກໂຕະພາຍຫຼັງກໍໄດ້. ລະບົບກັນຈອງໂຕະດຽວກັນຊ້ອນເວລາ (ເວລາເລີ່ມ + ໄລຍະນັ່ງ), ຈອງຍ້ອນຫຼັງບໍ່ໄດ້. ເບີໂທທີ່ກົງກັບລູກຄ້າ (CRM) ຈະຜູກໃຫ້ອັດຕະໂນມັດ.
- **ແຂກມາແລ້ວ**: ເປີດອໍເດີທີ່ໂຕະ (ຕ້ອງເປີດກະ) ພ້ອມຊື່ ແລະ ຈຳນວນແຂກ, ຜູກກັບລູກຄ້າເພື່ອສະສົມຄະແນນ; ປ່ຽນໂຕະຕອນຮັບແຂກໄດ້.
- ໜ້າ **ໂຕະ** ສະແດງປ້າຍ "ຈອງ HH:MM · ຊື່" ໃຫ້ໂຕະທີ່ມີການຈອງຕໍ່ໄປຂອງມື້ນີ້.
- ການຈອງບໍ່ລັອກໂຕະ: ຍັງເປີດໂຕະໃຫ້ລູກຄ້າ walk-in ໄດ້ ແລະ ບໍ່ມີການແຈ້ງເຕືອນ/ມັດຈຳ.

## Offline mode (ເຊີບເວີຫຼຸດຊົ່ວຄາວ)

ເຊີບເວີຢູ່ໃນຮ້ານ (LAN) ຈຶ່ງບໍ່ຕ້ອງໃຊ້ອິນເຕີເນັດ. ໂໝດນີ້ຊ່ວຍເມື່ອ Wi‑Fi ຕົກ ຫຼື ເຊີບເວີ restart ຊົ່ວຄາວ:

- ແອັບເປັນ PWA (ຕິດຕັ້ງເປັນແອັບໄດ້): ເປີດໄດ້ແມ້ເຊີບເວີຫຼຸດ ແລະ ສະແດງຂໍ້ມູນຄັ້ງລ່າສຸດ (ເມນູ, ໂຕະ, ອໍເດີ). ໃຊ້ໄດ້ຫຼັງຈາກເປີດຄັ້ງໜຶ່ງໃນຕອນທີ່ເຊື່ອມຕໍ່ແລ້ວ.
- ແຖບສີເຫຼືອງດ້ານເທິງບອກວ່າເຊື່ອມຕໍ່ບໍ່ໄດ້ ແລະ ລອງເຊື່ອມຕໍ່ໃໝ່ເອງທຸກ 5 ວິນາທີ.
- ການສັ່ງອາຫານເພີ່ມໃສ່ອໍເດີທີ່ເປີດຢູ່, ປ່ຽນສະຖານະລາຍການ ແລະ ໜ້າຈໍຄົວ ຖືກເກັບໄວ້ໃນເຄື່ອງ ແລ້ວສົ່ງອັດຕະໂນມັດເມື່ອກັບມາ (ບໍ່ສົ່ງຊ້ຳ — ໃຊ້ Idempotency-Key). ຖ້າເຊີບເວີບໍ່ຮັບ (ເຊັ່ນ ອໍເດີຖືກປິດແລ້ວ) ຈະຂຶ້ນແຖບສີແດງໃຫ້ກວດ.
- ຕ້ອງໃຊ້ເຊີບເວີ: ເປີດໂຕະ/ອໍເດີໃໝ່, ຊຳລະເງິນ, ໃບຄົວທີ່ພິມຈາກເຊີບເວີ, ປິດກະ ແລະ ການແກ້ໄຂຕ່າງໆ — ຈະແຈ້ງຕາມຕົວຈິງ ແລະ ກະຕ່າບໍ່ຫາຍ.

## ເຄື່ອງພິມ (ຄົວ / ບາ / ໜ້າຮ້ານ)
ເຊີບເວີເປັນຜູ້ພິມ ບໍ່ຕ້ອງກົດຢືນຢັນໃນ browser. ໂຕໜັງສືລາວຖືກແຕ້ມເປັນຮູບ (Noto Sans Lao) ແລ້ວສົ່ງເປັນຄຳສັ່ງ ESC/POS raster ຈຶ່ງໃຊ້ໄດ້ກັບເຄື່ອງພິມໃບບິນເກືອບທຸກຍີ່ຫໍ້ ເຖິງວ່າເຄື່ອງບໍ່ມີຟອນລາວ.

- **ຕັ້ງຄ່າ:** ເມນູ **ເຄື່ອງພິມ** → ເພີ່ມເຄື່ອງ (ໜ້າທີ່: ຄົວ/ບາ ຫຼື ໜ້າຮ້ານ, ການເຊື່ອມຕໍ່, ກະດາດ 58/80mm, ຈຳນວນສະບັບ, ຕັດກະດາດ) → ກົດ "ກວດການເຊື່ອມຕໍ່" ແລະ "ພິມທົດສອບ".
  - **LAN / Wi-Fi:** ໃສ່ IP ເຄື່ອງພິມ (port 9100). ຕັ້ງ IP ເຄື່ອງພິມໃຫ້ຄົງທີ່ ແລະ ຢູ່ວົງດຽວກັບເຄື່ອງແມ່ຂ່າຍ. ຮັບສະເພາະ IP ພາຍໃນຮ້ານ.
  - **USB:** ສຽບກັບເຄື່ອງທີ່ແລ່ນ LAZA, ຕິດຕັ້ງ driver ໃນ Windows ແລ້ວເລືອກຊື່ເຄື່ອງພິມ (ສົ່ງແບບ RAW ຜ່ານ print spooler).
  - Bluetooth ຍັງບໍ່ຮອງຮັບ.
- **ແບ່ງເສັ້ນທາງ:** ເມນູອາຫານ → ແກ້ໄຂໝວດ → "ສົ່ງໃບສັ່ງໄປເຄື່ອງພິມ" (ເຊັ່ນ ເຄື່ອງດື່ມ → ບາ). ໝວດທີ່ບໍ່ເລືອກ ອອກເຄື່ອງພິມຄົວເຄື່ອງທຳອິດ.
- **ພິມອັດຕະໂນມັດ:** ກົດ "ສົ່ງຄົວ", ລູກຄ້າສັ່ງ QR (ຫຼື ພະນັກງານຢືນຢັນ) → ໃບຄົວ/ບາ. "ພິມບິນ" ແລະ ໃບຮັບເງິນຫຼັງຊຳລະ → ເຄື່ອງໜ້າຮ້ານ. ພິມຊ້ຳໄດ້ຈາກລາຍລະອຽດລາຍການ ແລະ ປະຫວັດບິນ.
- **ເຄື່ອງພິມຂັດຂ້ອງ:** ງານພິມລໍຖ້າໃນຄິວ ແລະ ລອງໃໝ່ອັດຕະໂນມັດ 5 ຄັ້ງ; ມີແຈ້ງເຕືອນແດງຢູ່ແຖບຂ້າງ ແລະ ປຸ່ມ "ພິມໃໝ່" ໃນໜ້າເຄື່ອງພິມ.
- ຖ້າຍັງບໍ່ໄດ້ຕັ້ງເຄື່ອງພິມ ລະບົບຈະໃຊ້ໜ້າຕ່າງພິມຂອງ browser ຄືເກົ່າ.
- **ທົດລອງໂດຍບໍ່ມີເຄື່ອງແທ້:** `npm run fake-printer -w server -- 9100 9101 9102` ຈະເປີດເຄື່ອງພິມຈຳລອງ 3 ເຄື່ອງ ແລະ ບັນທຶກແຕ່ລະໃບເປັນຮູບໃນ `server/data/fake-printer/`. ໃສ່ IP `127.0.0.1` ກັບ port ເຫຼົ່ານັ້ນໃນໜ້າເຄື່ອງພິມ.
